# LitRPG: Подземелье Системы

Мод для Minecraft 1.21.1 (NeoForge). Вся игра — прохождение одного большого подземелья группой из 3–5 игроков:
Преддверие → 5 этапов по 10 уровней → титры. Рейдовые хранители с разметкой на полу, роли танк / боец / поддержка,
классы со своей идеей, личная добыча, голос «Системы».

- Описание игры: [docs/VISION.md](docs/VISION.md)
- План разработки: [PLAN.md](PLAN.md)
