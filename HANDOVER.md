## Фаза 0 — что есть
- NeoForge 1.21.1 (21.1.265), ModDevGradle 2.0.148, Gradle 9.2.1, Java 21.
- `Balance`: разделы в `data/litrpg/balance/<имя>.json`, строгие кодеки (пропущенное поле — ошибка, лишнее поле — предупреждение),
  `/reload`, рассылка клиентам (`BalanceSyncPayload`), `/litrpg balance [раздел]` — посмотреть, что загружено.
- Раздел `progression`: макс. уровень 50, класс на 10, опыт `100 + 90 × ур^1,85`, 10 очков характеристик (×0,3), 2 очка класса.
- Защита протокола: `Protocol.VERSION` + `net_protocol.txt` + `NetworkProtocolTest`.
- Тесты: JUnit (`ProgressionTest`, `NetworkProtocolTest`), GameTest (`CoreTests.balanceLoadsFromData`), CI на GitHub Actions.
- Dev-файлы: `dev_commands.txt` (сервер), `dev_screenshot.txt` (клиент); `tools/dev/prepare_run.sh` убирает экран первого запуска.
- Сервер на VPS настроен скриптами `tools/server/*` и проверен: dev-клиент зашёл по сети и получил баланс.

## Фаза 1 — что есть
- `player/`: `PlayerData` (вложение NeoForge, переживает смерть и перезаход), `PlayerService` — единственная точка изменений
  (опыт, уровень, роль, вложение очков → пересчёт → атрибуты → пакет клиенту), `PlayerEvents` (вход, голод всегда полон,
  естественная регенерация выключена правилом мира, своё восстановление 3%/с вне боя через 6 с).
- `StatBreakdown` — один расчёт на сервере и клиенте; каждая величина = сумма строк «источник: вклад» (окно «Расчёт»).
  Разделы баланса `character.json` (формулы) и `roles.json` (роли, рост характеристик до класса).
- Предел здоровья Minecraft (1024) снят access transformer'ом (`RangedAttribute.maxValue`), модификатор здоровья постоянный —
  здоровье не обрезается при перезаходе.
- Клиент: `HudOverlay` (здоровье числом и полосой с «призраком» урона, блок уровня, напоминание о свободных очках),
  `CharacterScreen` (K: Статус с предпросмотром вложения, Навыки — заготовка панели, Расчёт), `RoleScreen` (описание
  роли строится из roles.json через `RoleInfo`), `UiKit`/`SysButton` — стиль «Системы».
- Команды: `/litrpg level set|xp add|role|stats reset|stats show`.
- Dev: `tools/dev/open.sh character 2|role tank|close`, `tools/dev/shot.sh имя`, `tools/dev/srv.sh "команда"`.
- **Не сделано в фазе 1 (перенесено):** стартовый набор роли — в фазе 2 вместе с оружием (посох); навыки — фаза 3.

## Как поднять на другом ПК
1. JDK 21 (Temurin), git. `git clone https://github.com/Naholde/litrpg-dungeon`.
2. `./gradlew build` (первый раз скачивает Minecraft и NeoForge, ~5 мин).
3. Для dev-клиента — `bash tools/dev/prepare_run.sh`, затем `./gradlew runClient`.
4. Доступ к серверу — ключ `~/.ssh/litrpg_vps` (лежит только на ПК Андрея).
