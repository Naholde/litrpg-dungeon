## Решения владельца (ответы на вопросы 10.11)
- Редкость: каждая следующая **в 3 раза** реже предыдущей.
- Модели: **все** (хранители, монстры, торговец, призывы, тотемы, предметы боя) **и облик игрока по классу**.
  Стиль — **как Hytale**: крупные выразительные формы, текстура вдвое плотнее ванильной, изгибы из повёрнутых частей,
  мягкое затенение, каждая модель — своя, не из шаблона. У приёмов — свои анимации с эффектами, но без каши.
- Карта: **можно менять всё** — вертикаль, шахты-спуски («дроперы»), подъёмы с ловушками, паркур, залы разной формы и размера,
  новые загадки, развилки, секретки. Арена хранителя — под его приёмы (огромный сплеш → огромная арена).
- Эффекты навыков: короткие ударные — ярче и живут дольше; постоянные (тотемы, ауры, зоны) — тише, не перекрывают разметку.
